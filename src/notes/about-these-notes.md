> **Draft — not published.** This note is a placeholder that explains the section. It won't appear on the site until `draft: true` is removed from its front matter.

This is where shorter writing will live. The entries are smaller than the book and more considered than a social post.

**How to publish a note**

1. Add a Markdown file to `src/notes/`. The file name becomes the URL, so `src/notes/my-note.md` is published at `/notes/my-note/`.
2. Give it front matter: a `title`, a `date`, and an optional `description`.
3. Leave out `draft: true` when it's ready. Published notes show up on the Notes page and in the RSS and JSON feeds automatically.
